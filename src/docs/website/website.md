The archived website stores its docs and news articles in Markdown files and generates static pages from them. The former bug tracker has been replaced by a read-only notice.

## Guides

- [Markdown](./markdown) goes over the supported Markdown syntax, components and every available header field.
- [Archived Bug Tracker](./making_a_bug_report) preserves information about the former bug-report workflow.
- [Committing to the Docs](./committing_to_the_docs) goes over the full process of making and submitting a docs change.

The website is open source on [GitHub](https://github.com/VanillaSquared/Website). If something in these guides no longer matches the website, please update the guide together with your other changes.
