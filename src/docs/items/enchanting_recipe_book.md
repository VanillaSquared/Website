Enchanting Recipe Books replace enchanted books in loot and librarian trades. Each book contains one or more recipes for the new enchanting table.

Right-click the book to learn every unknown recipe stored inside it. The book is consumed after at least one recipe is learned. If you already know all of its recipes, the book is not consumed.

The books can be found in structure chests, through fishing, piglin bartering and librarian trades. Which recipe you get depends on where the book came from.

Read [Enchanting](/docs/enchanting) for the full enchanting table guide.
